# shadowsockstg

Телеграм-бот для управления Shadowsocks-подключениями и их раздачи.

Этот бот управляет подключениями Shadowsocks на сторонних серверах (их может быть несколько). Также он умеет выдавать конфигурации подключений пользователям Telegram, осуществлять переподключения, предоставлять бесплатный период использования, а также принимать оплату для пополнения баланса пользователя. 

Все действия на удаленных серверах выполняются по протоколу SSH.

---

## Порядок начальной установки бота на сервер

Выполните следующие команды в терминале:

```bash
sudo apt update
sudo apt install -y git                                 # Установка git перед клонированием репозитория проекта
git clone https://github.com/ramfromufa/shadowsockstg   # Клонирование проекта shadowsockstg
cd shadowsockstg                                        # Переход в директорию проекта
chmod +x setup.sh                                       # Перевод скрипта установки в режим исполняемого файла
./setup.sh                                              # Запуск скрипта установки
```

### Интерактивный процесс установки
В процессе работы скрипт ожидает от пользователя ввода следующих данных:

1. **Подтверждение установки Shadowsocks-libev на текущий сервер для теста:**
   * **При утвердительном ответе:** Скрипт может запросить пароль пользователя для выполнения операций через `sudo`. Затем он установит `shadowsocks-libev` на сервер телеграм-бота и скопирует файл `server_block_local.acl` из репозитория в директорию `/etc/shadowsocks-libev/acl/`. После этого скрипт еще раз запросит пароль для подключения к серверу по SSH и создаст в директории проекта файл `servers.json`, куда внесет данные о сервере. В данном сценарии бот и Shadowsocks будут запущены на одном сервере, а бот будет обращаться к своему же серверу извне для симуляции общения с удаленным хостом.
   * **При отказе:** Скрипт запросит данные другого сервера, на котором уже установлен `shadowsocks-libev` и настроен файл `.acl`. Данные также будут сохранены в файле `servers.json`.

2. **Настройка окружения:**
   Далее скрипт создаст и активирует виртуальное окружение в директории проекта для установки Python-библиотек, необходимых для запуска бота (`aiogram` и `fabric`). После установки библиотек окружение будет деактивировано.

3. **Данные Telegram:**
   Скрипт запросит токен бота и список ID администраторов — пользователей Telegram, которым будет предоставлен расширенный список команд для управления ботом.

4. **Создание службы systemd:**
   Скрипт автоматически создаст файл службы `/etc/systemd/system/shadowsockstg.service`, пропишет в нем необходимые пути для запуска бота и добавит переменные окружения с токеном и списком администраторов. После этого скрипт перезапустит `systemctl`, активирует автозапуск процесса `shadowsockstg` при перезагрузке сервера и выведет стандартный список команд для дальнейшего взаимодействия.

## Запуск и тонкая настройка

Для базового запуска бота достаточно выполнить команду:
```bash
sudo systemctl start shadowsockstg
```

Однако перед запуском есть возможность скорректировать ряд файлов проекта для более точной настройки.

### 1. Файл `servers.json`
Используется для добавления или удаления серверов Shadowsocks. Заполняется по следующему шаблону:

```json
{
    "1": {
        "name": "Название сервера с Shadowsocks-libev, отображаемое в боте",
        "ip": "IP-адрес сервера или домен, если он настроен",
        "login": "Пользователь стороннего сервера",
        "key": "Пароль пользователя стороннего сервера для управления по SSH",
        "prtkl": "ss",
        "location": "Amsterdam",
        "max_amount": 100 // Число: максимальное количество подключений для этого сервера
    },
    "2": {
        "name": "Example",
        "ip": "xx.xx.xx.xx",
        "login": "user",
        "key": "pass",
        "prtkl": "ss",
        "location": "The Ramfromufa islands",
        "max_amount": 10
    }
}
```

### 2. Файл `ff.py`
В самом конце этого файла можно изменить рабочие параметры бота:

```python
timedelta_rqst_vpn = 300    # Временной отрезок в секундах, в течение которого можно сделать ограниченное количество запросов на новое подключение
max_qntt_rqst_vpn = 5       # Количество запросов на новое подключение, доступное в этот отрезок времени
test_period = 86400         # Тестовый (бесплатный) период в секундах
```

### 3. Файлы локализации и тарифов
* `texts.json` — содержит тексты ответов бота на разных языках.
* `prices.json` — содержит тексты ответов, связанных с пополнением баланса, а также длительность периодов оплаты и цены.

После завершения настройки запустите или перезапустите бота:
```bash
sudo systemctl start shadowsockstg
```

## Хранение данных и логирование

* **База данных:** Данные пользователей (с привязкой только к их Telegram ID) хранятся в файле базы данных SQLite `db.db`.
* **Логи:** Все запросы подключений для отладки логируются в файл `log.txt` В формате, понятном одному лишь творцу. Этот файл используется системой, поэтому **удалять его не следует** без предварительной корректировки исходного кода бота, иначе программа завершится с ошибкой.
